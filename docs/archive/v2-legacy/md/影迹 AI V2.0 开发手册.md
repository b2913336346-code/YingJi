影迹 AI V1.0

模块前端 UI、客户端逻辑与后端分离开发手册

影迹 Android 个人版 · 可复制 Codex Prompt · 以真实代码和测试证据为准

# 1. 模块定位

影迹 AI 是同一个 Android 应用中的独立逻辑模块，不是第二个 APK。模块分成 Android 前端 UI、Android 本地业务逻辑、Cloudflare Worker/DeepSeek 后端，最后通过接口契约集成。

- 个人使用，不考虑公开上线、多用户运营或订阅商业化。

- DeepSeek 单模型，经 Cloudflare Worker 代理；Android 不直连模型。用户自行提供 DeepSeek API Key（BYOK），不提供开发者共享 Key。

- 首页嵌入 AI 模块，不新增底部导航，延续黑白极简风格。

- 候选必须来自可验证且许可允许的数据源；模型不能凭空制造真实候选。

- 用户确认后才能将推荐加入影迹现有作品库。

- 本地画像来源授权与向外部服务传输摘要是两个独立边界。

# 2. AI 固定规则

- 首次进入 AI 功能时引导，允许跳过；跳过不代表全部授权，也不触发模型调用。

- 个人评分来源默认关闭、观看行为来源默认关闭、AI 推荐反馈来源默认开启；若冻结基线有冲突先报告，不静默选择。

- 明确偏好优先于推断偏好；硬条件与明确排除不可被静默放宽。

- 候选不足时显示实际数量，不补造作品；已看完/想看不直接等于喜欢。

- 历史默认最近 20 次会话、最长 30 天；数据源许可更严格时优先遵守许可。

- 每日初始建议 30 次成功 AI 业务任务，不代表供应商免费额度。

- 建议模型超时 15 秒、最多自动重试 1 次，仅对可恢复错误重试；不自动切换模型。

## 已冻结的模型 API 接入架构（设计约束）

**唯一允许的调用链：Android App → Cloudflare Workers → DeepSeek API。**

- Android 客户端不得直接请求 DeepSeek API，也不得将任何真实 API Key 硬编码、明文存入资源或打包进 APK；用户运行时输入的 Key 仅加密存储于应用私有区域。
- 用户自带 DeepSeek API Key（BYOK）使用 Android Keystore 支持的加密机制本地保存；调用时通过 HTTPS 临时发送给受控 Worker，Worker 不持久化、不记录；仅 Worker 自身服务端密钥放在 Secret。
- 不在 Android 设备本地运行或部署大语言模型。
- Worker 负责请求校验、访问控制、防滥用、服务端额度/并发控制、超时与错误映射、幂等和用量统计。客户端不能通过 APK 内置静态令牌获得可靠身份认证；部署前需明确可验证的访问控制与限流策略。
- Android 只发送当前任务必需且用户已授权的最小画像摘要；不上传完整本地作品库。
- DeepSeek 负责理解用户需求、分析画像和生成推荐提示；真实候选必须由可验证且许可允许的数据源提供，再经过本地过滤与排序。
- 本文件是设计与开发基线，不代表 Worker 已部署、DeepSeek API 已接通或真实 API 测试已完成。


## BYOK 决策与安全边界

- 已确认方案 B：用户自带 DeepSeek Key，个人版不提供开发者共享模型 Key；只支持 DeepSeek。
- 用户 Key 在 Android 本地加密保存，Worker 仅临时转发。此方案中 Worker 可接触原始 Key，须由用户信任 Worker 部署方。
- Worker 侧额度只约束影迹业务任务，无法代替 DeepSeek 账户真实余额或支出上限。
- A3-BYOK、A5-BYOK 是新增专项 Prompt；原 A5 其他字段与异常要求仍有效，冲突时以 BYOK 专项约束为准。
