
# 影迹基础应用开发手册
## 前端 UI 与本地数据层分离｜直连 API 架构兼容修订版

> 本文件保留基础影迹原有范围，仅补充与影迹 AI 直接调用 DeepSeek API 的边界。本文是设计基线，不代表代码已实现或测试已通过。

# 1. 目标与边界

影迹基础应用与影迹 AI 共用同一个 Android 项目和 APK，但职责分离。基础影迹以本地数据层为主，不需要为了 AI 接入新增 Worker 或云端后端。

- 前端 UI：Jetpack Compose 页面、导航、表单、加载/错误/空状态。
- 本地数据层：Room、DAO、Repository、业务用例、迁移、图片本地存储。
- 影迹 AI 的 DeepSeek API 请求由 Android 客户端通过 HTTPS 直接发起；本手册不负责实现 AI 网络层。
- AI 网络错误不得影响基础作品管理。
- 保持黑白极简风格，不擅自增加功能。

# 2. 基础功能范围

| 模块 | 范围 | 验收重点 |
|---|---|---|
| 作品管理 | 新增、编辑、删除、名称、分类必选、标签可选 | 新增编辑规则一致、重复作品处理明确 |
| 观看记录 | 想看、观看中、已看完、观看时间、补录、评分 | 状态和时间正确、重启后保留 |
| 分类/标签 | 管理、作品关联、数量统计 | 关联正确，重复输入不崩溃 |
| 检索展示 | 搜索、状态/分类/时间筛选、海报墙/列表 | 结果正确 |
| 海报与设置 | 本地海报、我的/统计、默认排序和展示设置 | 不联网抓取海报 |
| 持久化 | Room、迁移、异常写入处理 | 不清空数据库规避迁移 |

# 3. 与影迹 AI 的边界

- 作品库仍由基础应用本地 Repository/Room 管理。
- AI 不得直接写基础 DAO；用户确认加入推荐作品后，调用现有新增用例。
- DeepSeek API 不可用时，基础作品管理仍应正常工作。
- API Key 属于影迹 AI 配置，不得写入作品数据库、日志、测试报告或版本控制。
- BYOK 表示每位用户使用自己的 Key，不是把开发者公共 Key 打包进 APK。Keystore 加密可降低静态泄露风险，但无法保证运行时密钥绝对不可提取。
- 不自动联网下载海报；影视候选真实性与来源须独立验证。

# 4. 执行顺序

1. 发送 B0 全局约束。
2. 发送 B1 只读审查。
3. 确认后修复本地数据层，再修改 UI。
4. 执行基础功能回归，作为 AI 集成基线。

# Prompt B0｜全局约束

```text
维护现有影迹 Android 项目，不新建项目。先检查 Git 状态、未提交改动、真实目录、构建入口、测试和文档。每次只执行当前阶段，不重写整个项目。保护作品、分类、标签、观看状态/时间、评分、搜索与本地海报。数据库变更必须有迁移和数据保留测试，不得清库规避问题。不得删除/弱化测试断言或伪造结果。未经批准不提交、推送、发布或执行破坏性操作。每阶段报告修改文件、diff、真实测试结果、未完成项和风险，然后停止。MuMu 优先但非强制，优先尝试 <MuMu安装目录>/nx_main/MuMuNxMain.exe；不可用时可用其他设备并记录真实环境。
本次只处理基础影迹。AI 的 DeepSeek API 采用 Android HTTPS 直连，不使用 Worker 代理；本次不实现 AI 网络层。基础功能不得依赖 AI 可用性。
```

# Prompt B1｜只读审查

```text
只读审查基础影迹，禁止修改文件或清空数据库。检查 Git、导航、作品新增编辑、分类/标签、搜索筛选、状态时间、评分、海报、Room Schema/迁移、DAO、Repository、ViewModel 和测试。输出真实架构、已实现/部分实现/未实现/未知清单、文件映射、缺陷风险、可运行命令及结果、最小修复计划。不得猜测状态。完成后停止。
```

# Prompt B2｜本地数据层

```text
只修复已确认的数据层问题。先列文件和迁移风险。检查写入事务、分类/标签关联、trim/空名称/重复名称、数据库失败反馈、海报文件引用和迁移。禁止清库、删测试断言或重写无关模块。测试空白/重复输入、快速点击、插入失败、重启持久化和迁移保留。报告后停止。
```

# Prompt B3｜基础 UI

```text
只处理已批准的基础 UI，不增加 AI 功能。检查列表/海报墙、作品新增编辑、分类标签、我的/统计、设置。保持黑白极简风格，分类必选、标签可选，新增编辑规则一致。UI 不直接操作 DAO。测试关键交互，报告证据后停止。
```

# Prompt B4｜回归验收

```text
回归新增/编辑/删除作品、分类标签、搜索筛选、状态时间、评分、本地海报、统计、重启持久化、迁移和错误提示。每项标记通过/失败/未执行并附证据。P0/P1 未关闭不得判通过。MuMu 优先但非强制，记录实际环境。输出冻结建议并停止。
```

# 5. 交付门槛

- 核心流程有真实测试结果，未执行项明确列出。
- 迁移与持久化有证据，不以清库规避问题。
- AI 网络故障不影响基础影迹。
